MOH System — Privacy Policy

Last updated: November 19, 2026

1. Introduction

This Privacy Policy explains how MOH System (“the Bot”) processes information when it is used in Discord servers. The Bot is an independently operated Discord application and is not operated by Discord.

2. Information the Bot Processes

Depending on the features enabled and how a server uses the Bot, it may process and store:

  • Discord user IDs and server (guild) IDs.
  • Staff points, task titles and types, task targets, assigned member IDs, and task progress.
  • Administrative audit records, which may include the acting user's ID, the affected user's ID, action type, details, and timestamp.
  • Server-specific configuration, such as rank order, role permissions, protection settings, selected log channels, and other feature settings.
  • Command or interaction information needed to carry out a requested feature.

The Bot's code uses a local SQLite database file for staff points, tasks, task progress, and audit records, and also uses configuration files for some server settings. The hosting provider may separately process technical data needed to run the Bot.

3. How Information Is Used

Information is used to operate the Bot's features, including staff management, points and tasks, rank and permission configuration, moderation or protection features, audit logs, and troubleshooting.

4. Messages and Discord Access

The Bot requests Discord permissions and gateway intents needed for its features. It may process message content when required for prefix commands or message-based task features. It is not intended to collect private messages generally or read information unrelated to its features.

5. Sharing and Third Parties

MOH System does not sell personal information. Information may be handled by Discord as part of the Discord platform and by the Bot's hosting provider to operate the service. Information may also be disclosed where required by law or where reasonably necessary to protect the Bot, its users, or server communities. The Bot operator should not grant database or hosting access to people who do not need it.

6. Storage and Retention

Stored information is kept in the Bot's database and configuration files on its hosting environment. The current code does not define one universal retention period for all records. Some records, such as task and audit history, may remain until they are manually removed or the relevant data is otherwise deleted. Hosting backups, if enabled by the provider, may have separate retention periods.

7. Data Requests and Deletion

To ask a question about information associated with your Discord account, or to request deletion where applicable, contact the MOH System team through the support server below. Include the relevant server and Discord user ID where possible. Some information may need to be retained for legitimate operational, security, or legal reasons. Removing the Bot from a server does not necessarily delete data already stored for that server.

8. Security

The operator takes reasonable steps to limit access to stored information. No storage system or internet transmission can be guaranteed to be completely secure. Server owners should also carefully manage the Bot's permissions and access to staff or audit information.

9. Children's Privacy

The Bot is a Discord community management tool and is not designed to collect information directly from children. Users must follow Discord's age requirements and applicable laws when using Discord and the Bot.

10. Changes to This Policy

This policy may be updated when the Bot's features or data practices change. The latest version will be published at this page with an updated date.

11. Contact

For privacy questions or data requests, contact the MOH System team through the MOH System Support Server.
